One voicemail greeting, recorded by a cat. `main.py` (Python 3.13
stdlib only, no network) writes the greeting to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), after validating it against the
competition gate: UTF-8 text, 1–120 characters, not whitespace-only, one
line, no control characters, and a byte-exact write-back check.

The entry:

> You've reached Miso. I'm busy knocking your mug off the table. Leave a message, or better, bring snacks.

104 characters. The greeting is the cat speaking, not the owner writing
about a cat: Miso is mid-crime, knocking a mug off the table, and the
punch — "or better, bring snacks" — lands in the last three words, with
the cat's own priority replacing the apology a caller expects.

## Run

```sh
python3 main.py
```
